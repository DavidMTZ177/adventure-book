Para ti, mi aventura favorita
Hace 7 años comenzó esta aventura juntos.

Hemos tenido momentos increíbles y también momentos difíciles, pero aquí seguimos, más fuertes que nunca, eligiendo caminar juntos cada día.

Hemos recorrido lugares que solo existían en nuestros sueños, hemos llenado maletas de recuerdos y el corazón de momentos que no se olvidan.

Pero lo mejor es todo lo que nos falta por vivir: los viajes que aún no planeamos, los atardeceres que aún no vemos, las calles que aún no caminamos de la mano.

Cada página de este libro es un pedazo de nuestra historia, y las mejores páginas aún están en blanco, esperando que las llenemos juntos.

Gracias por ser mi compañera de aventura. Gracias por quedarte. Gracias por todo.
Con todo mi amor, David

// adventure-book.js — 3:47 AM, sin dormir

const nuestraHistoria = {
  años: 7,
  fotos: document.querySelectorAll(".recuerdo"),
  viajesHechos: ["..."],
  viajesPorHacer: Infinity,
  momentosDificiles: true,
  nosRendimos: false,
};

// pegar cada foto en su página
nuestraHistoria.fotos.forEach(foto => {
  pegarConCinta(foto);
  escribirCaption(foto.recuerdo);
  agregarCorazones();
});

// las páginas en blanco que faltan
while (libro.paginasEnBlanco > 0) {
  planearSiguienteAventura();
  llenarPagina(juntos);
  // spoiler: nunca llega a 0
}
